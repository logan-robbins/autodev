## Root (Note density)

OpenAI’s ChatGPT for Financial Services lists three jobs: develop research, build financial models, create customized client materials.

Here’s the Autodev playbook to ship those as production systems — not a Work tab demo:

1) Research → data contracts + source-of-truth map + citation gate. Artifact in a ledger, not a chat thread.
2) Models → assumptions ledger + replayable pipeline + owner stamp. Last week’s inputs must reproduce last week’s outputs.
3) Client packs → template lock, bound to research + model run id, review queue only after both gates pass, export lock with receipts.

Same three outcomes. Diagram and UAT gates in the how-to below.
