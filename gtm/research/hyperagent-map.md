## What HyperAgent is (public)

- Managed cloud agents: identity, instructions, tools, knowledge, Skills, Memories, Rubrics.
- You configure once → invoke via thread / Slack / Telegram / email / webhook / schedule / MCP client.
- Broad tool surface: browser, shell/code, media gen, SaaS connectors (Slack, GitHub, Sheets, etc.).
- Monetization: monthly credit plans (documented $20–$10k bands with bonus credits); ChatGPT OAuth can offset some model spend.
- Founding narrative: Howie Liu / Airtable lineage; enterprise knowledge-work fleet, not "hire a stealth eng team."
- Weaknesses buyers still own: governance, credential scope, Skill drift, cost-per-accepted-task, exit/portability, security review of subprocessors (Composio incident May 2026 disclosed).

**Implication:** HyperAgent wins when the buyer wants *self-serve agent ops* in days. It loses when the buyer needs *frontier software shipped* without building an internal agent-ops org.

## Kill / Copy / White-space

### KILL (do not compete here)

- Self-serve agent builder / fleet console for marketing, ops, research workflows.
- "Stand up an agent in Slack in 10 minutes" demo war.
- Credit-metered DIY agent runtime as the product.
- Competing on connector count, Skills marketplace, or LLM-as-judge fleet dashboards.
- Positioning as "another AI coding SaaS you configure."

### COPY (steal the language / motion, not the product)

- **Proof of compounding methods** → our version is Pillars/Pods + contracts + ledgers (visible delivery), not buyer-authored Skills.
- **Invocation where work lives** → we stay LinkedIn/sales-led; do not become a Slack bot company. Steal *clarity of "who does the job"* messaging.
- **Evidence trail** → HyperAgent sells run history; we sell verified output + handoff evidence (site already claims this — lean harder).
- **Itemized economics** → they itemize credits; we already itemize platform license ($100/agent/mo) + onshore hours + AI subs + tokens. Keep quotes brutally transparent.
- **X foil voice** → short contrast posts: "platform you babysit" vs "team you hire that runs the platform." Demand owns creative; Research owns claim accuracy.

### WHITE-SPACE (own hard)

1. **Talent density as the product** — stealth / top-lab-caliber engineers (OpenAI/Anthropic/Apple/Meta/Amazon/NVIDIA caliber claim on site) *operating* the harness, not the buyer.
2. **Hybrid human–AI staff-aug at fractional rates** — not a tool seat; not offshore body shop. Human judgment + Autodev velocity; quality held by operators, cost held by parallel harnesses.
3. **100% onshore** — procurement/security-friendly vs SaaS agent black box or offshore staff-aug.
4. **Full SDLC delivery to done** — architecture judgment → parallel Claude Code/Codex harnesses → contract-checked software in *their* GitHub/cloud. HyperAgent is workflow automation; we are product/platform build capacity.
5. **AI clean room / air-gap option** — security story for regulated / sensitive codebases that will not dump IP into a general agent SaaS.
6. **Buyer still "hiring a team"** — category refusal of DIY PaaS; one-liner: *You're still hiring expensive engineers. They just run Autodev — so you can finally afford them.*

## Objection map (sales use)

| Buyer says | HyperAgent pull | Autodev answer |
|---|---|---|
| "We'll just buy an agent platform" | Self-serve, fast pilot | Who architects, reviews, and ships the product? Platform ≠ delivery capacity. |
| "Our eng team will run agents" | Skills compound in-house | Then you're building an agent-ops tax. We *are* that capacity, already staffed. |
| "Security / data residency" | Managed cloud + review burden | Clean room + air-gap option + delivery into their cloud. |

| "Prove it" | Demos of Slack agents | Live demo UI + scoped pilot Pillar with contracts and evidence. |
